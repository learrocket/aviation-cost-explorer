# 1903 Management — Aircraft Ownership Calculator

Discover the true cost of aircraft ownership. Adjust aircraft, owners, flying hours, and charter preferences to see how shared ownership and charter operations can reduce your costs.

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Development

Requires Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
# Install dependencies
npm i

# Start the development server (http://localhost:8080)
npm run dev
```

## Building

```sh
npm run build
```

## Deployment

Deployed on Vercel at [1903management.vercel.app](https://1903management.vercel.app). Pushes to `main` on GitHub trigger a redeploy.
